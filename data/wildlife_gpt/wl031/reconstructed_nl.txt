If a person imports into this state an animal that is protected by this code at a time when the season is closed for any wild bird, wild game bird, wild fowl, wild game animal, game animal, game bird, nongame animal, reptile, amphibian, fish, game fish, nongame fish, finfish, shark, crab, shellfish, aquatic animal life, aquatic plant, seagrass, bat, wolf, armadillo, dangerous wild animal, deer, mule deer, white-tailed deer, desert bighorn sheep, pronghorn antelope, alligator, frog, turtle, exotic animal, exotic livestock, exotic fowl, carcass, fillet, steak, fin, or other animal, then the person must not import that animal unless the person has subchapter authorization at that time.
