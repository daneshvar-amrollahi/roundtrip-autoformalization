## Arrow 1: Original NL → Phase 1 SMT

The Original NL states: An operator may not drive on the left side of center to pass **unless** (i) authorized **and** (ii) the left side is clearly visible and free of approaching traffic for sufficient distance to pass without interfering.

This means: if using the left side to pass → must be authorized AND left side must be clear.

The Phase 1 SMT encodes:
```
(=> (and (on_roadway v r t) (using_opposing_direction_lane_to_pass v t))
    (or (and (in_authorized_lane v t)
             (left_side_clear_for_passing v r t)
             (forall ((u Vehicle)) ...))
        (not (using_opposing_direction_lane_to_pass v t))))
```

The consequent is a disjunction: either (conditions are met) OR (not using opposing lane to pass). But the antecedent already asserts `(using_opposing_direction_lane_to_pass v t)`, so `(not (using_opposing_direction_lane_to_pass v t))` would be false whenever the antecedent is true. This makes the disjunct logically redundant — it doesn't change the truth value when the antecedent holds. So logically, the formula simplifies to: if using opposing lane to pass → (authorized AND clear AND safely_clear). This matches the Original NL semantics.

However, this is a structural oddity but not a semantic error. The encoding is logically equivalent to the correct one. Arrow 1 is **correct**.
